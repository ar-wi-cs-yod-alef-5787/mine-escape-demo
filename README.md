# Mine Escape

Complete classroom game solution for phone and console.

Collect all diamonds, then reach the exit. Use the on-screen arrows on your phone. After collecting a pickaxe, walk into a wall to break it.

Three levels: Patrol, Pursuit, Frenzy. The console and browser versions share the same C# map and game logic.

## Source code

Download and extract `MineEscape-Demo.zip`. It contains the complete C# solution and browser project. The private student template is maintained separately.

## Automatic publication

GitHub Actions extracts the source archive, builds the console project and publishes the browser game to GitHub Pages. Updating the source archive automatically updates the site.
